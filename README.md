# نمایشگر آنلاین پاورپوینت

## راه‌اندازی (یک‌بار)
1. این پوشه را به‌عنوان یک مخزن جدید در GitHub آپلود کنید (شاخه `main`).
2. فایل پاورپوینت را در مسیر `presentation/` بگذارید، مثلاً `presentation/talk.pptx`.
3. در **Settings → Pages → Source** گزینه **GitHub Actions** را انتخاب کنید.
4. Commit/Push کنید. تب **Actions** را ببینید؛ بعد از ۲–۴ دقیقه آدرس سایت نمایش داده می‌شود.

## تغییر ارائه
فقط فایل داخل `presentation/` را جایگزین و Push کنید؛ سایت خودکار بازسازی می‌شود.

## نکات
- اسلایدها در GitHub Actions با LibreOffice به تصویر تبدیل می‌شوند (حفظ ظاهر، فونت و طرح). انیمیشن‌ها و ترنزیشن‌ها منتقل نمی‌شوند.
- فونت‌هایی که روی سرور نصب نباشند جایگزین می‌شوند؛ برای دقت بیشتر فونت‌های سفارشی را داخل پاورپوینت Embed کنید.
- Speaker Notes واقعی از فایل خوانده می‌شود. اسلایدهای مخفی نمایش داده نمی‌شوند.
- میانبرها: ← → Space جابه‌جایی · F تمام‌صفحه · P حالت ارائه‌دهنده · G فهرست · Esc خروج.
- روی آیفون، Safari تمام‌صفحه واقعی ندارد؛ حالت «تمام‌صفحه» رابط را فشرده می‌کند (برای حالت کامل: Share → Add to Home Screen).
